隱私權政策

忽田各漫畫作品集 App（com.comicpunch.notify）

概述

「忽田各漫畫作品集」（以下簡稱「本 App」）由同人誌社團「猛少女之拳」開發與營運。我們重視您的隱私，本政策說明 App 收集、使用及儲存資料的方式。

本 App 的主要功能為瀏覽漫畫作品，不要求使用者註冊帳號，也不收集任何個人身份資訊（如姓名、電子郵件、電話號碼等）。

我們收集的資料

1. Firebase Cloud Messaging (FCM) Token

  • 內容：由 Google Firebase 自動產生的裝置識別碼（非個人資訊）
  • 用途：發送漫畫更新通知
  • 傳送至：我們的自建伺服器（stvfu.com），僅用於推播通知
  • 保留期間：Token 失效後即不再使用，伺服器不會主動清除歷史紀錄

2. 網路連線資訊

  • 內容：IP 位址（伺服器存取日誌自動記錄）
  • 用途：伺服器正常運作與安全防護
  • 保留期間：依伺服器日誌輪替設定，通常保留 14 天

3. 本機儲存資料

  • Cookie：用於通關密語解鎖狀態（comic_unlock），有效期 90 天，僅存於您的裝置
  • localStorage：用於記錄 UI 偏好設定（如關閉提示橫幅），僅存於您的裝置
  • 離線快取：您主動下載的章節圖片，儲存於 App 內部儲存空間，可隨時刪除

我們不會做的事

  • 不收集個人身份資訊（PII）
  • 不使用第三方分析或廣告追蹤工具
  • 不將任何資料出售或分享給第三方
  • 不追蹤您的瀏覽行為或閱讀紀錄
  • 不要求存取相機、麥克風、通訊錄或位置等敏感權限

App 權限說明

  • INTERNET — 載入漫畫內容與傳送 FCM Token
  • POST_NOTIFICATIONS（Android 13+）— 顯示漫畫更新推播通知，您可隨時在系統設定中關閉

第三方服務

本 App 使用 Google Firebase Cloud Messaging 進行推播通知。Firebase 的資料處理方式請參閱 Firebase 隱私權政策。

兒童隱私

本 App 不以 13 歲以下兒童為目標受眾，也不會故意收集兒童的個人資訊。

政策更新

我們可能不定期更新本隱私權政策。更新後的版本將發佈於本頁面，並標註最後更新日期。
